# DepotPrint-mises-a-jour

Mises à jour automatiques de **Dépôt Print** (affiches et étiquettes rayon Electro Dépôt).

À l'ouverture, Dépôt Print lit `derniere.json`. S'il y a une version plus récente, il propose
de l'installer : il télécharge le zip, vérifie son empreinte SHA-256, puis redémarre tout seul.

Ce dépôt ne contient que le code du logiciel : aucun catalogue, aucune photo, aucune donnée.
